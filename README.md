# Cavernícola 🦣

Joc de plataformes fet amb pygame. Juga-hi al navegador:
https://eduardbenet.github.io/Game/

## Jugar en local

    ./run.sh

Fletxes (o A/D): moure · Espai: saltar (doble salt a l'aire) · M: usar l'arma · Esc: sortir

## Web

Cada `push` a `main` construeix el joc amb [pygbag](https://github.com/pygame-web/pygbag)
i el publica a GitHub Pages (vegeu `.github/workflows/deploy.yml`).
